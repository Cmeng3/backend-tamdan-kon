## Repositary description
This repo is used for storing **Tamdan-Kon api** project folder. 

## Technology used
**Tamdan-Kon api** is developing using Laravel framework.

## Main purpose of Tamdan-Kon api
To gathering information such as **geocoding** and **student Id** from IoT devices, and store those information in mysql DB for future used by mobile-application to render those information for monitoring purpose
